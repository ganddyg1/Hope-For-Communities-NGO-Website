# \# Cost Optimization

# 

# This project was designed to minimize hosting costs.

# 

# \- Amazon S3 was used for static website hosting.

# \- Amazon CloudFront was used to cache content globally.

# \- No EC2 instances or databases were required.

# \- Static hosting reduces infrastructure and maintenance costs.

# \- CloudFront improves loading speed while reducing repeated requests to the S3 bucket.

# 

# This architecture is suitable for NGOs because it provides fast, secure, and affordable web hosting.
